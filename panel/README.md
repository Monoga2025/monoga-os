# Panel administrativo local

Abra [index.html](index.html) con doble clic en un navegador moderno. La página usa `styles.css` y `app.js` del mismo directorio; no requiere instalación, servidor ni conexión de red.

## Qué se puede hacer

- Escribir en la búsqueda para filtrar tarjetas, propuestas y filas visibles. `/` enfoca la búsqueda y `Escape` la limpia.
- Usar la navegación lateral para saltar a cada sección.
- Abrir tarjetas, etapas del flujo, AIDA y pilotos para leer detalles y seguir enlaces a documentos locales.
- Abrir **Tareas** para marcar recordatorios. Las marcas se guardan solo en el almacenamiento local de ese navegador, si está disponible.
- Cambiar tema con el botón de sol. El selector de periodo cambia **cifras de ejemplo**. El icono de campana abre recordatorios ilustrativos.

## Estado de los datos

La etiqueta **«Vista demostrativa · cifras de ejemplo»** se aplica a todos los números de indicadores, barras, porcentajes y recuentos de la captura. No son resultados, ingresos, clientes, campañas ni tareas observadas de Daniel. Los dos pilotos son hipótesis de oferta, sin precio aprobado. Los dolores del contenido son preguntas para validar. Los documentos enlazados contienen el material de trabajo y sus fuentes.

Esta interfaz no autentica usuarios, no envía mensajes, no publica, no accede a Odoo ni a NotebookLM y no modifica el libro Excel. Los controles operan sobre esta página y, cuando procede, sobre preferencias locales del navegador.

## Revisión visual

La pantalla objetivo es de 1540 × 1024. El diseño adapta tarjetas y navegación a ventanas estrechas. La implementación se basa en HTML, CSS e iconos SVG, con texto y controles reales; la captura no se usa como fondo.
